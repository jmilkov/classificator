# Воркеры (Workers)

Этот каталог содержит фоновые скрипты и коннекторы для работы с брокерами сообщений, базами данных временных рядов и Zabbix.

---

## 1. MQTT to VictoriaMetrics Worker (`mqtt-to-vm.js`)

Этот воркер предназначен для потокового сбора данных с MQTT-брокера и их передачи в систему хранения временных рядов VictoriaMetrics.

### Функциональность
- **MQTT Подписка:** Подписывается на топики (по умолчанию `#`) и слушает входящие сообщения.
- **Парсинг данных:**
  - Извлекает `device_id` из структуры MQTT-топика.
  - Поддерживает рекурсивную распаковку JSON-объектов, включая вложенные JSON-строки (часто используемые в микросервисах, например, с одинарными кавычками).
  - Очищает данные: отсекает нечисловые значения, служебные поля времени и метаданные.
- **Интеграция с VictoriaMetrics:**
  - Преобразует полученные метрики в формат InfluxDB Line Protocol (в виде `spk3,device_id=...,packet_type=...`).
  - Извлекает `timestamp` из пакета (если присутствует) для точной временной привязки.
  - Отправляет данные через HTTP POST запрос на `/api/v1/write`.
  - Поддерживает Basic Auth.

## 2. Zabbix History Import Worker (`zabbix-import-history.js`)

Скрипт единоразовой миграции (backfill) для загрузки исторических данных сенсоров (uv, l12, l13, l4) из Zabbix в VictoriaMetrics. Запускается вручную.

### Функциональность
- **Обнаружение хостов:** Подключается к Zabbix API, находит все активные хосты, у которых есть указанные элементы данных (items).
- **Синхронизация состояния:** 
  - Проверяет текущее самое старое значение (минимальный timestamp) в VictoriaMetrics по каждой метрике.
  - Сохраняет прогресс в локальный файл `public/config/zabbix_checkpoint.json`.
- **Импорт истории (Backfilling):** 
  - Запрашивает «сырую» историю из Zabbix (`history.get`) двигаясь **назад во времени** (чанками по 24 часа).
  - Глубина архива ограничена 1 годом или датой первой записи.
  - Автоматически форматирует метрики (`uv` преобразуется в `packet_type=ultra`, а уровни в `packet_type=cond`) для совместимости с общим Line Protocol `mqtt-to-vm`.
  - Отправляет загруженные пакеты напрямую в VictoriaMetrics API порциями.

### Настройка (Переменные окружения)
Оба скрипта читают настройки из базы данных `app_config` (zabbixUrl, zabbixUser, zabbixPassword) и из файла `.env`:
- `ZABBIX_URL`: Базовый URL (на случай, если не прочитается из БД).
- `VM_URL` / `VM_WRITE_URL`: Базовый адрес VictoriaMetrics (с портом `8428`).
- `VM_USER` / `VM_PASSWORD`: Basic Auth учетные данные от VictoriaMetrics.
